About & privacy

Class Name Picker is a free classroom tool for picking who recites and making groups. It is built so that children's names and photos never leave this device.

Safe for your class

  • No information is sent over the internet. There is no server that receives data.
  • No accounts, passwords or sign-in.
  • No ads, trackers, analytics or cookies.
  • No other websites are contacted. Every page has a security rule that blocks it.
  • No camera, microphone or location. Photos are chosen with the normal file picker.
  • No programs are installed. "Install app" only adds a shortcut to this web page.

What is saved, and where

Only on this device, in this browser's own storage:

  • class names, students' names and photos (made small)
  • settings such as language, theme, sounds and group options
  • who has been called, and the last groups made

Files you save

Save backup saves one class as a .json file. Save these groups saves the group lists as a .csv file for Excel or Google Sheets. Both are made on this device and go to your Downloads folder. Keep them private, because they contain children's names.

Working offline

The first time the app opens, the browser keeps a copy of the app's own files (not your class data), so it works without internet. When it is opened online later, it checks for a newer version.

Removing data

  • One class: Class options → Delete this class on the teacher screen.
  • One student: the × on the student's card.
  • Everything: clear this website's data in the browser settings, or uninstall the app.

Children's privacy

The app is run by the teacher. Children only watch Spin Time and Group Time. No information about children is collected by anyone other than the teacher, on the teacher's own device, in line with the Philippine Data Privacy Act of 2012 (RA 10173).
