# Privacy policy

*Class Name Picker. Last updated 26 October 2026.*

Class Name Picker is a classroom tool used by teachers with young children. It is built so that **no personal information ever leaves the teacher's device**.

## What the app stores

Everything is stored **only on the device and browser where it is used**, in the browser's own storage (IndexedDB):

- class names
- students' names
- students' photos, if the teacher adds them (made small, about 30 KB each)
- settings: language, theme, sounds, group options
- who has been called in Spin Time, and the last groups made

## What the app does not do

- It does **not** send any information over the internet. There is no server that receives data.
- It does **not** use accounts, passwords or sign-in.
- It does **not** use ads, analytics, trackers or cookies.
- It does **not** contact any other website. Every page has a Content Security Policy that blocks it.
- It does **not** use the camera, microphone or location. Photos are chosen by the teacher with the normal file picker.
- It does **not** share information with anyone.

## Files the teacher saves

- **Save backup** saves a `.json` file with one class (names, photos and settings) to the teacher's Downloads folder.
- **Save these groups** (Group Time) saves a `.csv` file with the group lists.

These files are created on the device and are never uploaded. The teacher decides where they go. Please keep them private, as they contain children's names and photos.

## Offline copy of the app

The first time the app is opened, the browser keeps a copy of the app's own files (not any class data) so it can work without internet. When the app is opened online later, it checks for a newer version of those files.

## Removing data

- One class: **Class options → Delete this class** on the teacher screen.
- One student: the **×** on the student's card.
- Everything: clear this website's data in the browser's settings (Site data / Storage), or uninstall the app.

## Children's privacy

The app is used by teachers, not by children on their own. Children only watch the Spin Time and Group Time screens. No information about children is collected by anyone other than the teacher, on the teacher's own device. This is in line with the Philippine Data Privacy Act of 2012 (Republic Act No. 10173) and children's privacy principles.
